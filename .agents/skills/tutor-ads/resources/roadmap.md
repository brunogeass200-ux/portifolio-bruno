# 🗺️ Roadmap ADS — Trilha de Aprendizado Completa

Este roadmap é uma trilha guiada para estudantes de Análise e Desenvolvimento de Sistemas.
Siga na ordem sugerida, mas sinta-se livre para pular tópicos que já domina.

---

## Fase 1: Fundamentos (Meses 1-3) 🌱

### 1.1 Lógica de Programação
- [ ] Entender variáveis e tipos de dados
- [ ] Dominar operadores aritméticos, lógicos e relacionais
- [ ] Estruturas condicionais (if/else, switch)
- [ ] Estruturas de repetição (for, while, do-while)
- [ ] Funções e procedimentos
- [ ] Vetores e matrizes
- **Linguagem sugerida**: Python ou Portugol (VisuAlg)
- **Projeto**: Calculadora completa no terminal

### 1.2 Algoritmos e Pseudocódigo
- [ ] Escrever algoritmos em pseudocódigo
- [ ] Criar e interpretar fluxogramas
- [ ] Entender complexidade básica (rápido vs lento)
- **Ferramenta**: Flowgorithm ou draw.io

### 1.3 Matemática Computacional
- [ ] Lógica proposicional (E, OU, NÃO, tabela verdade)
- [ ] Sistemas numéricos (binário, octal, hexadecimal)
- [ ] Conjuntos e funções básicas
- **Aplicação**: Entender como o computador toma decisões

---

## Fase 2: Programação de Verdade (Meses 4-6) 🌿

### 2.1 Python Aprofundado
- [ ] Listas, dicionários, tuplas, sets
- [ ] Manipulação de strings
- [ ] Leitura e escrita de arquivos
- [ ] Tratamento de exceções (try/except)
- [ ] Módulos e imports
- **Projeto**: Sistema de gestão de notas de alunos (arquivo CSV)

### 2.2 Git e Controle de Versão
- [ ] git init, add, commit, push, pull
- [ ] Branches e merge
- [ ] GitHub: repositórios, issues, pull requests
- [ ] .gitignore e README.md
- **Projeto**: Publicar todos os exercícios no GitHub

### 2.3 Banco de Dados Relacional
- [ ] Modelo Entidade-Relacionamento (MER)
- [ ] SQL: DDL (CREATE, ALTER, DROP)
- [ ] SQL: DML (INSERT, UPDATE, DELETE, SELECT)
- [ ] JOINs (INNER, LEFT, RIGHT)
- [ ] Funções de agregação (COUNT, SUM, AVG, MAX, MIN)
- [ ] GROUP BY e HAVING
- **SGBD sugerido**: MySQL ou PostgreSQL
- **Projeto**: Banco de dados para uma loja virtual

---

## Fase 3: Orientação a Objetos e Web (Meses 7-10) 🌳

### 3.1 Java / C# — POO
- [ ] Classes e objetos
- [ ] Construtores e destrutores
- [ ] Encapsulamento (public, private, protected)
- [ ] Herança e classes abstratas
- [ ] Polimorfismo
- [ ] Interfaces
- [ ] Coleções (ArrayList, HashMap)
- [ ] Padrão MVC básico
- **Projeto**: Sistema de cadastro de funcionários

### 3.2 Estruturas de Dados
- [ ] Listas encadeadas (simples e dupla)
- [ ] Pilhas (Stack) — aplicação: validar parênteses
- [ ] Filas (Queue) — aplicação: fila de atendimento
- [ ] Árvores binárias — aplicação: busca eficiente
- [ ] Tabelas hash — aplicação: dicionário
- [ ] Noção de grafos
- **Projeto**: Implementar cada estrutura do zero

### 3.3 Desenvolvimento Web — Frontend
- [ ] HTML5 semântico
- [ ] CSS3 (Flexbox, Grid, responsividade)
- [ ] JavaScript ES6+ (let/const, arrow functions, template literals)
- [ ] DOM manipulation
- [ ] Fetch API e consumo de APIs REST
- [ ] Framework CSS (Bootstrap ou Tailwind)
- **Projeto**: Portfólio pessoal responsivo (como o que você já está construindo! 🎉)

### 3.4 Desenvolvimento Web — Backend
- [ ] Node.js e Express.js (ou Spring Boot / Django)
- [ ] Rotas e middleware
- [ ] Conexão com banco de dados
- [ ] APIs REST (GET, POST, PUT, DELETE)
- [ ] Autenticação básica (JWT)
- **Projeto**: API para o sistema de cadastro

---

## Fase 4: Profissional (Meses 11-14) 🌲

### 4.1 Engenharia de Software
- [ ] Requisitos funcionais e não-funcionais
- [ ] Diagramas UML (Use Case, Classes, Sequência)
- [ ] Metodologias ágeis (Scrum, Kanban)
- [ ] Testes de software (unitário, integração)
- **Ferramenta**: Astah, Lucidchart ou draw.io

### 4.2 Frameworks Modernos
- [ ] React.js ou Angular (frontend)
- [ ] Spring Boot ou Django (backend)
- [ ] ORM (Hibernate, Sequelize, ou Django ORM)
- **Projeto**: Aplicação fullstack completa

### 4.3 DevOps e Deploy
- [ ] Docker básico (Dockerfile, docker-compose)
- [ ] CI/CD conceitos (GitHub Actions)
- [ ] Deploy em nuvem (Vercel, Railway, Heroku)
- [ ] Variáveis de ambiente e segurança
- **Projeto**: Fazer deploy do portfólio e de um projeto

### 4.4 Segurança
- [ ] OWASP Top 10
- [ ] SQL Injection e como prevenir
- [ ] XSS e CSRF
- [ ] HTTPS e certificados SSL
- [ ] Hash de senhas (bcrypt)

### 5.1 Projeto Integrador / TCC
- [ ] Definir tema e escopo
- [ ] Documentação técnica completa
- [ ] Desenvolvimento iterativo
- [ ] Apresentação e defesa

### 5.2 Preparação para o Mercado
- [ ] Currículo e LinkedIn otimizados
- [ ] Portfólio no GitHub
- [ ] Contribuição em projetos open source
- [ ] Praticar entrevistas técnicas (LeetCode, HackerRank)
- [ ] Soft skills: comunicação, trabalho em equipe
