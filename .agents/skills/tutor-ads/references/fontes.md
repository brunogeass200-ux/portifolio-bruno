### Programação
- 📘 **"Python Crash Course"** — Eric Matthes
- 📘 **"Eloquent JavaScript"** — Marijn Haverbeke (gratuito online)
- 📘 **"Use a Cabeça! Java"** — Kathy Sierra (excelente para POO)
- 📘 **"Clean Code"** — Robert C. Martin (boas práticas)

### Banco de Dados
- 📙 **"Sistemas de Banco de Dados"** — Ramez Elmasri & Shamkant Navathe
- 📙 **"SQL para Análise de Dados"** — Cathy Tanimura

### Web Development
- 📕 **"HTML e CSS: Projete e Construa Websites"** — Jon Duckett (visual)
- 📕 **"JavaScript: O Guia Definitivo"** — David Flanagan

### Engenharia de Software
- 📓 **"Engenharia de Software Moderna"** — Marco Tulio Valente (gratuito online)
- 📓 **"Scrum: A Arte de Fazer o Dobro do Trabalho na Metade do Tempo"** — Jeff Sutherland
